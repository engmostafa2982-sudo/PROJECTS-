# Weekly Progress Report Attachment
Weekly Progress Report Attachement
Contractor/Consultant should ensure that the weekly progress report are supported with required attachment.

Those attachment should include the following as a minimum requirement:

Approved Primavera P6 Schedule in .xer format.
3-5 latest progress photographs in JPG format
Updated Primavera P6 schedule in .xer format & PDF Format Three weeks look ahead in PDF format. (as per plf link)
Remaining Works in PDF format.
Any other supporting document required per the development of the project.
